================================================================================
                    下一步操作（重要！）
================================================================================

【第1步】在微信开发者工具中构建npm

1. 打开微信开发者工具
2. 打开项目：miniprogram-10
3. 点击顶部菜单：工具 → 构建npm
4. 等待构建完成（会生成 miniprogram_npm 文件夹）

⚠️ 这一步非常重要！如果不构建npm，小程序将无法找到mqtt库！

【第2步】配置开发设置

在微信开发者工具中：
1. 点击右上角"详情"按钮
2. 选择"本地设置"标签
3. ✅ 勾选"不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书"
4. ✅ 勾选"启用npm"（如果还没勾选的话）

说明：这样开发阶段就可以连接本地IP地址的MQTT服务器

【第3步】确保EMQX服务器运行

打开命令行，执行：
cd D:\A大三上学期实验课\C51单片机实验\My-Project\LCW-Project\2\LCW\emqx-5.0.26-windows-amd64\bin
emqx.cmd console

看到 "EMQ X Broker is started successfully!" 说明启动成功

【第4步】确保上位机运行

1. 运行 LCW\bin\Debug\LCW.exe
2. 连接串口
3. 连接MQTT（192.168.184.16:1883）
4. 确认能接收到STM32传感器数据

【第5步】测试小程序

1. 在微信开发者工具中点击"编译"
2. 在模拟器中点击"连接服务器"按钮
3. 观察连接状态是否变为"已连接"（绿色）
4. 查看是否能实时接收传感器数据
5. 测试报警功能（让传感器数据超过阈值）

================================================================================
                        数据流程说明
================================================================================

[STM32] → 串口 → [上位机LCW.exe] → MQTT主题LCW2 → [EMQX服务器]
                                                         ↓
                                                    WebSocket
                                                         ↓
                                                  [微信小程序]
                                                         ↓
                                                    解析显示

数据格式（JSON）：
{
  "timestamp": "2025-12-15 04:13:00.123",
  "temperature": 19,
  "humidity": 43,
  "waterLevel": 0,
  "airQuality": "nice",
  "warning": false,
  "rawData": "温度:19℃   湿度:43%RH   水位:0%   Air:nice"
}

================================================================================
                        常见问题排查
================================================================================

【问题1】点击"连接服务器"后一直显示"未连接"
→ 检查EMQX是否运行
→ 检查是否勾选"不校验合法域名"
→ 检查控制台日志是否有错误信息
→ 确认IP地址是否正确（app.js中的192.168.184.16）

【问题2】提示"未找到模块mqtt"
→ 确认是否执行了"工具 → 构建npm"
→ 检查是否有 miniprogram_npm 文件夹
→ 如果没有，重新执行构建npm

【问题3】连接成功但收不到数据
→ 检查上位机MQTT是否连接成功
→ 确认上位机发布到LCW2主题
→ 查看小程序连接日志是否有"数据更新"信息
→ 检查控制台Console标签的详细日志

【问题4】数据显示为"--"
→ 等待1-2秒，STM32每1.5秒发送一次数据
→ 检查JSON解析是否成功（看日志）
→ 确认字段名匹配（temperature、humidity等）

【问题5】真机预览时无法连接
→ 手机和电脑必须在同一WiFi网络
→ 检查电脑防火墙是否允许8083端口
→ 使用手机浏览器访问 http://电脑IP:18083 测试连通性
