================================================================================
                        立即开始使用
================================================================================

【第1步】构建npm（必须执行！）

1. 打开微信开发者工具
2. 打开项目：miniprogram-10
3. 点击顶部菜单：工具 → 构建npm
4. 等待构建完成

【第2步】配置本地设置

1. 点击右上角"详情"按钮
2. 选择"本地设置"标签
3. ✅ 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"
4. ✅ 勾选"启用npm"

【第3步】启动EMQX服务器

打开命令行，执行：
cd D:\A大三上学期实验课\C51单片机实验\My-Project\LCW-Project\2\LCW\emqx-5.0.26-windows-amd64\bin
emqx.cmd console

【第4步】运行上位机程序

1. 运行 LCW\bin\Debug\LCW.exe
2. 连接串口
3. 连接MQTT（192.168.184.16:1883）
4. 确认能接收到STM32传感器数据

【第5步】运行小程序

1. 在微信开发者工具中点击"编译"
2. 打开首页，查看欢迎界面
3. 切换到传感器页面，会自动连接MQTT
4. 观察传感器数据是否实时更新
5. 尝试修改报警阈值
6. 切换到摄像头页面，输入ESP32摄像头IP地址

================================================================================
                        图标自动切换说明
================================================================================

📊 温度传感器
   - 正常：温度.png
   - 报警：温度_报警状态.png（当温度 > 阈值时）

💧 湿度传感器
   - 正常：湿度.png
   - 报警：湿度_报警状态.png（当湿度 > 阈值时）

🌊 水位传感器
   - 正常：水位.png
   - 报警：水位_报警状态.png（当水位 > 阈值时）

🌫️ 空气质量传感器
   - 良好：空气质量优状态.png（airQuality === 'nice'）
   - 污染：空气质量劣状态.png（airQuality === 'bad'）

🔔 蜂鸣器
   - 正常：蜂鸣器-关状态.png（warning === false）
   - 报警：蜂鸣器-开状态.png（warning === true）

⚠️ 只要任意一个传感器超过阈值或空气质量为bad，蜂鸣器就会自动切换到开状态！

================================================================================
                        摄像头使用说明
================================================================================

1. 确保ESP32摄像头已上电并连接WiFi
2. 在串口监视器中查看摄像头的IP地址
3. 手机与摄像头需要在同一WiFi网络
4. 在摄像头页面输入IP地址（例如：192.168.1.100:81）
5. 点击"连接摄像头"按钮
6. 等待加载后即可看到实时画面

常见地址格式：
- http://192.168.1.100:81/stream
- http://192.168.1.100:81/cam

================================================================================
                        常见问题解决
================================================================================

❓ 传感器页面显示"MQTT未连接"
→ 检查EMQX服务器是否运行
→ 检查是否勾选"不校验合法域名"
→ 确认IP地址是否正确（app.js中的192.168.184.16）

❓ 提示"未找到模块mqtt"
→ 确认是否执行了"工具 → 构建npm"
→ 检查是否有miniprogram_npm文件夹

❓ 传感器数据不更新
→ 检查上位机MQTT是否连接成功
→ 确认上位机发布到LCW2主题
→ 查看控制台是否有错误信息

❓ 报警图标不切换
→ 检查阈值设置是否正确
→ 确认传感器数据是否超过阈值
→ 查看images文件夹是否包含所有图标

❓ 摄像头无法连接
→ 确认ESP32摄像头已上电
→ 手机和摄像头必须在同一WiFi
→ 检查输入的IP地址是否正确
→ 尝试在浏览器中访问该地址测试
